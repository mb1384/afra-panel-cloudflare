# راهنمای توسعه‌دهنده

---

## ساختار کد

پروژه یک monorepo با npm workspaces است:

| بسته | مسئولیت |
|---|---|
| `@afra/shared` | منطق خالص: adapterهای پروتکل، فرمت‌های اشتراک، توازن بار، مسیریابی، اسکیماهای Zod |
| `@afra/control-plane` | Worker مدیریتی: API، احراز هویت، Cron، یکپارچه‌سازی Cloudflare |
| `@afra/edge` | Worker لبه: تحویل اشتراک + endpoint VLESS |
| `@afra/web` | رابط کاربری React فارسی RTL |

### اصل کلیدی: منطق خالص در shared

هر منطق قابل‌آزمون (تولید کانفیگ، توازن بار، مسیریابی، محاسبهٔ سهمیه) در `packages/shared` به‌صورت
**تابع خالص** بدون وابستگی به دیتابیس یا محیط نوشته شده است. این کار تست‌پذیری را بالا می‌برد و
به Worker لبه اجازه می‌دهد همان منطق را بدون تکرار استفاده کند.

---

## افزودن قابلیت جدید

### پروتکل جدید

۱. یک کلاس جدید در `packages/shared/src/protocols.ts` بنویسید که `ProtocolAdapter` را پیاده کند.
۲. آن را در `REGISTRY` ثبت کنید.
۳. تست‌های snapshot برای خروجی URI و Clash اضافه کنید.

هیچ تغییری در UI یا هسته لازم نیست — فرم‌ها از `getMetadata()` تغذیه می‌شوند.

### فرمت اشتراک جدید (مثلاً sing-box)

۱. یک adapter در `packages/shared/src/subformats.ts` بنویسید که `SubFormatAdapter` را پیاده کند.
۲. در `FORMAT_REGISTRY` ثبت کنید.
۳. در `detectFormatFromUserAgent` قاعدهٔ تشخیص اضافه کنید.

### کانال اعلان جدید

`notify()` در `modules/notifications/notifications.service.ts` را گسترش دهید یا یک adapter جدید
بسازید.

## قراردادها

- **TypeScript strict** در همهٔ بسته‌ها.
- هر route: اعتبارسنجی Zod → بررسی مجوز → منطق → ثبت رویداد.
- هر عملیات مدیریتی باید در **گزارش رویدادها** ثبت شود.
- پیام‌های خطای کاربر **فارسی**؛ جزئیات فنی در لاگ سرور.
- هیچ اعتبارنامه‌ای در لاگ یا پاسخ API نباید ظاهر شود (لایهٔ redaction را رعایت کنید).
- تست برای منطق امنیتی و مالی (سهمیه، انقضا، اشتراک) **اجباری** است.

---

## اجرای تست‌ها

```bash
npm test                # همهٔ تست‌ها در محیط واقعی Workers
npm run test:watch -w @afra/control-plane
```

تست‌ها در `workerd` (همان موتور تولید) با D1 محلی اجرا می‌شوند. مهاجرت‌ها به‌صورت خودکار روی
دیتابیس ایزولهٔ هر فایل تست اعمال می‌گردند.

```bash
npm run lint
```
